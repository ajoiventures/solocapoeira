Important Notes

Small but important truth-in-advertising details.

This is not a TypeScript app yet.

The current source and test files are JavaScript/JSX. The older tools page mentioned TypeScript, but this repo does not include an active tsconfig.

Secrets stay outside the repo.

Use .env.local locally and GitHub Actions secrets in CI. The service cards show what keys are expected without exposing values.

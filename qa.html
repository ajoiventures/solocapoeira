Tools Out There for This

No single tool replaces a launch QA platform. The real setup is a stack: automation, accessibility, performance, observability, analytics, and manual evidence.

Playwright

Best fit for your repo today. Use it for browser flows, mobile viewports, navigation, settings, persistence, and smoke tests.

Already installedE2EMobile
Lighthouse CI

Adds repeatable performance, accessibility, best-practice, SEO, and PWA audits to CI against a production-like build.

Add nextPerformancePWA
axe-core / axe DevTools

Use axe in Playwright for automated accessibility scans, then use the browser extension for guided manual WCAG review.

Add nextA11yWCAG
Sentry

Runtime error reporting and release health. Your repo already has Sentry wiring that activates when the DSN is configured.

PostHog

Product analytics for event correctness, funnels, retention, and whether core loops are being used after launch.
